SUPER SIMPELE VERSIE

Bestanden:
- connect.php = verbinding met database
- database.sql = database en tabel maken
- register.php = account maken (CREATE)
- login.php = inloggen
- account.php = account bekijken (READ)
- account_bewerken.php = account aanpassen (UPDATE)
- account_verwijderen.php = account verwijderen (DELETE)
- logout.php = uitloggen

Gebruik:
1. Maak in XAMPP/MySQL de database met database.sql.
2. Zet de map in htdocs.
3. Open register.php.
4. Maak een account.
5. Log in.

Geen CSS, geen framework en alleen basis PHP + MySQLi.
